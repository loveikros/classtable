# 03: 学校网页首次导入

**What to build:** 学生在 App 内打开西柚研究生选课网页，自行登录并打开“我的课表”弹窗，然后预览解析结果，为学期命名并保存离线课表。

**Blocked by:** 01 离线课表基础。

**Status:** ready-for-agent

- [ ] App 内打开学校选课网页；用户可按学校现有流程登录并主动触发弹窗导入。
- [ ] 导入预览展示解析出的课程安排及数量，用户确认后才保存；取消或失败保持已有数据。
- [ ] 解析星期、起止节次、周次、课程名称、班级、教师和地点；空地点可保存。
- [ ] 同一表格单元格中不同适用周次的课程分别保存，连续节次的同一课程合并为一次安排。
- [ ] 只保留课表所需字段，不保存整份网页和无关个人信息；离线可查看导入结果。
- [ ] 使用去标识化的真实弹窗结构样本自动化验证导入；记录真实设备上登录与弹窗流程的验收结果或待验风险。

## Comments

- 2026-10-22：已实现 App 内网页登录、主动提取、预览和新学期事务保存。`SchoolImportTest` 使用从已保存 `#wdkbTable` 弹窗截取并去标识化的表格结构，覆盖同格分周、连续节次合并和空地点；测试 APK 已编译，设备端测试尚未运行。
- 待验风险：本环境无法使用 adb，且没有可用于学校登录的实机账号，因此学校现网登录、弹窗触发与导入操作尚未经过真实设备验收。学校页面变化可能影响提取。
