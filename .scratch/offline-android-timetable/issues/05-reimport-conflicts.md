# 05: 重新导入与冲突处理

**What to build:** 学生主动更新已有学期的学校课表，先查看来源变化及与手动修改的冲突，逐项选择后再提交，保留自己确认的调整。

**Blocked by:** 03 学校网页首次导入。

**Status:** ready-for-agent

- [ ] 用户可选择已有学期并主动重新导入；重复导入相同课表不会产生重复课程安排。
- [ ] 预览展示新增、删除和变更的学校来源安排，并标出与手动修改冲突的项目。
- [ ] 未冲突的手动修改继续保留；冲突由用户逐项选择最终结果。
- [ ] 用户确认后一次性更新本地课表；取消或解析失败时原课表完全保留。
- [ ] 自动化覆盖相同来源、来源变化、手动覆盖、冲突选择和取消提交。
