# 07: 本地备份与恢复

**What to build:** 学生可以把全部学期课表导出为本地文件，在另一台手机预览并恢复；教务系统密码不随文件迁移。

**Blocked by:** 02 日期例外；04 保存教务凭据；05 重新导入与冲突处理。

**Status:** ready-for-agent

- [ ] 导出包含学期、当前学期选择、周次锚点、学校来源课程安排、手动修改及日期例外。
- [ ] 备份文件按用户选择不加密，且不包含密码或其他教务登录凭据。
- [ ] 恢复前检查文件格式与版本，并预览学期及课程数量；用户确认后才写入。
- [ ] 无效或损坏的备份不会覆盖现有数据；恢复后断网可浏览原有各学期。
- [ ] 自动化覆盖完整往返、密码排除、旧版本处理和损坏文件拒绝。
