# 01: 离线课表基础

**What to build:** 学生可以在 Android App 中创建和切换学期，确认周次锚点，手动维护课程安排，并在断网时查看当前周和其他周。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 用户可创建、命名和切换多个学期；旧学期仍可回看。
- [ ] 用户可确认某个日期的学期周次；跨过周一后当前周自动递增，并可重新校准。
- [ ] 用户可添加、修改、删除按星期、起止节次和适用周次安排的课程，且手动修改有可见标记。
- [ ] 当前周为默认视图，可切换其他周；同一时段不同周次的课程按所选周正确显示。
- [ ] 退出并重新打开 App、以及断网时，学期、周次锚点和课程安排保持可用。
- [ ] 自动化从用户可见行为验证跨周一、跨学期和编辑后的展示结果。
