# 06: 2×2 当日课程小组件

**What to build:** 学生可把 2×2 小组件添加到 Android 桌面，在离线状态下看到当天正在上或接下来的两门课及剩余课程数。

**Blocked by:** 02 日期例外。

**Status:** ready-for-agent

- [ ] 小组件提供可添加的 2×2 布局，在常见桌面尺寸下内容可读。
- [ ] 根据当前学期、周次锚点及日期例外显示正在上或接下来的两门课的名称、时间和地点；正在上的课排第一。
- [ ] 超过两门时显示“另有 N 门”；当天无课显示“今日无课”，全部结束显示“今日课程已结束”。
- [ ] 打开 App、切换当前学期或修改课表后立即刷新；日常刷新允许少量延迟且不要求精确闹钟特殊权限。
- [ ] 自动化验证当日状态、更多课程计数和修改后的刷新；在真实 Android 桌面核查 2×2 布局与后台刷新延迟。

## Comments

- 2026-10-23：已添加 2×2 小组件、30 分钟周期更新及 App 渲染后的主动刷新。节次时间可在 App 内按学校铃声调整；桌面尺寸与后台刷新延迟仍需实机核对。设备端自动化已编译，但当前没有连接的设备。
