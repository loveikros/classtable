# 04: 保存教务凭据

**What to build:** 学生可选择保存教务系统密码；再次登录时，设备身份验证成功后才可向已核实的学校登录页面填入，也可随时删除保存的凭据。

**Blocked by:** 03 学校网页首次导入。

**Status:** ready-for-agent

- [ ] 保存密码是用户主动选择的操作；凭据由设备保护的加密密钥保管。
- [ ] 每次取用保存的密码前要求设备生物识别或锁屏验证；取消或失败时不填入。
- [ ] 仅在经核实的学校登录页面使用保存的凭据，页面地址不匹配时拒绝填入。
- [ ] 用户可删除保存的凭据；删除后不会再自动填入。
- [ ] 密码不进入课表数据、日志或崩溃信息；使用假登录页与假凭据完成自动化验证。

## Comments

- 2026-10-23：按用户要求移除保存、填入和删除教务密码的界面与实现；App 启动时清除旧版保存的凭据和密钥。本 issue 当前未实现。
