# 02: 日期例外

**What to build:** 学生可以为单个日期记录停课、补课或地点等信息变化，并在该日期看到调整后的课表，不影响其他周的常规课程安排。

**Blocked by:** 01 离线课表基础。

**Status:** ready-for-agent

- [ ] 用户可选择具体日期，对课程安排设置停课或信息变更，也可新增当天补课。
- [ ] 日期例外仅影响指定日期；同一课程在其他适用日期仍按常规安排显示。
- [ ] 若编辑常规课程后，已关联的停课或信息变更不再对应当天适用的课程安排，该例外不作为独立课程显示；仅独立补课可在没有常规课程时显示。
- [ ] 当天课表能区分日期例外与常规课程安排，编辑和删除例外后立即更新。
- [ ] 日期例外在 App 重启及断网后仍存在。
- [ ] 自动化覆盖停课、补课、地点变更和不受影响的相邻周。
