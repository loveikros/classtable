# Domain Docs

This is a single-context project.

Before work that changes course, semester, week, or import behavior, read the root `GLOSSARY.md` and use its terms. For any area with an ADR under `docs/adr/`, read the relevant decision before changing that area.

If a term or hard-to-reverse decision needs definition, update the glossary or add an ADR through the domain-modeling workflow. Existing documents are created only when needed.
